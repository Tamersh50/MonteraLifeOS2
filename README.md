# Montera Life OS — دليل التشغيل

نظام تشغيل شخصي: مهام، مشاريع، اجتماعات، بانتظار رد، ملاحظات، تقويم، إحصاءات، تقارير — بقاعدة بيانات سحابية (Supabase)، حفظ فوري، ومزامنة لحظية بين أجهزتك.

## 🆕 تحديث النسخة الاحترافية — ماذا أفعل؟

هذه النسخة أضافت: الوضع الداكن/الفاتح، تنبيهات ذكية + إشعارات متصفح، سحب وإفلات في Kanban، إحصاءات ورسوم بيانية، تقويم شهري، وقت متوقع وتمديد المهام ووسم «عاجل»، **خطوات إنجاز داخل كل مهمة (Checklist)**، **تقارير قابلة للطباعة/PDF**، و**استعادة كلمة المرور**.

للتحديث نفّذ خطوتين فقط:

1. **تحديث قاعدة البيانات** (مرة واحدة لخطوات الإنجاز): Supabase → SQL Editor → New query → الصق محتوى `migration_subtasks.sql` → Run.
2. **رفع الواجهة الجديدة**: في مستودع GitHub افتح `index.html` → قلم التعديل → احذف الكل → الصق محتوى `index.html` الجديد → Commit changes. ثم في المتصفح اضغط Ctrl+Shift+R.

بياناتك القديمة تبقى كما هي تماماً.

### استعادة كلمة المرور
في شاشة الدخول: اكتب بريدك ثم اضغط «نسيت كلمة المرور؟» → يصلك رابط على بريدك → افتحه → عيّن كلمة مرور جديدة. (يتطلب أن يكون Supabase قادراً على إرسال البريد — يعمل افتراضياً.)

## التثبيت من الصفر

المكوّنات:
- `index.html` — التطبيق كاملاً (ملف واحد، بدون خطوات بناء).
- `schema.sql` — قاعدة البيانات (شغّله مرة واحدة).

---

## الخطوة 1 — إنشاء مشروع Supabase (مجاني)

1. ادخل إلى `https://supabase.com` → **Start your project** → سجّل بحساب GitHub أو بريد.
2. **New project** → اختر اسماً (مثلاً `montera-life-os`) → ضع **Database Password** قوية واحفظها → اختر أقرب منطقة (Frankfurt أو Bahrain) → **Create**.
3. انتظر دقيقة حتى يجهز المشروع.

## الخطوة 2 — إنشاء قاعدة البيانات

1. من القائمة اليسرى: **SQL Editor** → **New query**.
2. افتح ملف `schema.sql`، انسخ محتواه بالكامل، الصقه في المحرر.
3. اضغط **Run** (أو Ctrl+Enter). يجب أن تظهر رسالة نجاح خضراء. هذا ينشئ الجداول والعلاقات والحماية (RLS) والمزامنة اللحظية دفعة واحدة.

## الخطوة 3 — تعطيل تأكيد البريد (اختياري لكن أسهل)

حتى تدخل فوراً دون رسالة تفعيل:
1. **Authentication** → **Sign In / Providers** → **Email**.
2. أطفئ **Confirm email** → **Save**.

## الخطوة 4 — نسخ مفاتيح الاتصال

1. **Project Settings** (الترس) → **API**.
2. انسخ قيمتين:
   - **Project URL** — مثل `https://abcd1234.supabase.co`
   - **anon public** key — نص طويل يبدأ بـ `eyJ...`
   
> المفتاح `anon` آمن للاستخدام في المتصفح لأن حماية الصفوف (RLS) مُفعّلة — كل مستخدم يرى بياناته فقط. **لا تستخدم** مفتاح `service_role` أبداً في التطبيق.

## الخطوة 5 — نشر التطبيق أونلاين

اختر طريقة واحدة:

**أ) GitHub Pages (مجاني):**
1. أنشئ Repository جديداً على GitHub (Private).
2. ارفع `index.html` (و `schema.sql` و `README.md` للتوثيق).
3. **Settings → Pages → Source: Deploy from branch → main → /(root) → Save**.
4. بعد دقيقة يظهر رابط مثل `https://username.github.io/repo/`.

**ب) Netlify / Vercel (أسرع):**
- اسحب مجلد المشروع إلى `https://app.netlify.com/drop` — يعطيك رابطاً فوراً.

**ج) تجربة محلية:**
- افتح `index.html` مباشرة بالمتصفح، أو شغّل `python -m http.server` داخل المجلد.

## الخطوة 6 — أول دخول

1. افتح رابط التطبيق.
2. تظهر شاشة **ربط قاعدة البيانات**: الصق **Project URL** و **anon key** → **اتصال**. (تُحفظ في متصفحك فقط.)
3. تظهر شاشة الدخول → **حساب جديد** → أدخل بريدك وكلمة مرور (٦ أحرف فأكثر) → **إنشاء الحساب**.
4. يفتح النظام وتُنشأ مجالاتك الافتراضية تلقائياً (الجامعة، الجودة، البحث، الشركات، شخصي). عدّلها من تبويب **المجالات**.

## الاستخدام اليومي

- كل صباح افتح **لوحة القيادة** → إحاطة الصباح تلخّص يومك في سطر، ثم مهام اليوم والمتأخر والاجتماعات وبانتظار رد.
- زر **＋ جديد** أعلى اليمين لإضافة أي عنصر بسرعة.
- كل تغيير يُحفظ فوراً في السحابة، ويظهر على أجهزتك الأخرى خلال ثوانٍ.

## المرونة والتوسّع

- **مجال جديد** (كلية/شركة/قسم): تبويب المجالات → ＋ مجال. لا حاجة لأي تعديل بالكود.
- **إضافة حقل أو جدول**: عدّل `schema.sql` وأضف نموذجاً في `FORMS` داخل `index.html`.

## الجاهزية للذكاء الاصطناعي

بياناتك في PostgreSQL قابلة للقراءة عبر Supabase API أو اتصال مباشر — أي وكيل ذكاء اصطناعي مستقبلي (Montera AI) يستطيع قراءتها وتحليلها بمفتاح `service_role` من جانب الخادم فقط.

## ملاحظات أمان

- لا تشارك مفتاح `service_role` إطلاقاً.
- المفتاح `anon` في `index.html` مقبول مع RLS، لكن يُفضّل إبقاء المستودع Private.
- لتغيير إعدادات الاتصال لاحقاً: زر «تغيير إعدادات الاتصال» في شاشة الدخول.
